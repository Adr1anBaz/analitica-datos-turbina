# Notebooks

Empezar con **`01_carga_y_variables.ipynb`**. Contiene imports, carga de los cinco CSV anuales, unión en `df` con una columna de procedencia `anio` y diccionario de variables, siguiendo el estilo inicial de los ejercicios del profesor. No limpia, divide ni entrena modelos; no se generan gráficas todavía.

Desde la raíz del repositorio: `uv run jupyter lab`. Al crear un notebook, usar el kernel **Python 3 (ipykernel)** del entorno iniciado con ese comando.

Abrir el notebook y ejecutar sus celdas de arriba hacia abajo con `Shift+Enter`, o usar **Run → Run All Cells**. Requiere haber descargado los originales con `uv run python -m scripts.descargar_datos`.
