# Setup Scania APS

Alcance aprobado: descarga local, entorno aislado reproducible, documentación de uso y repositorio privado. No entrenar modelos, limpiar datos ni empezar exploración predictiva.

## Decisiones

- Python 3.12.12 con uv y uv.lock; no cambiar instalaciones globales.
- Datos originales UCI, entrenamiento y prueba separados, excluidos de Git.
- Descargar y verificar con biblioteca estándar, hashes SHA-256 fijados y sin sobrescribir archivos locales diferentes.
- Dependencias: pandas, NumPy, matplotlib, seaborn, scikit-learn, JupyterLab e ipykernel.
- Repo privado `Adr1anBaz/analitica-datos-scania-aps`, creado con Browser Control; push por SSH de la misma cuenta.

## Comprobaciones

- Pruebas de preámbulo, encabezado, ancho, etiquetas, hash y protección de archivos locales.
- Conteos originales: 60,000/16,000 filas, 171 columnas incluyendo etiqueta.
- Imports y arranque del kernel Jupyter del entorno.
- Datos y .venv excluidos del índice; ningún material ajeno al proyecto en el commit.
- Confirmar privacidad y contenido remoto después de subir.
